# L’Atelier N°04

Site vitrine du salon de coiffure homme à Marbella.

## Lancer

```bash
npm install
npm run dev
```

Le site s’ouvre sur [http://localhost:3000](http://localhost:3000).

## Coordonnées

Le téléphone, WhatsApp, l’e-mail, Instagram et le lien d’itinéraire se règlent dans `lib/salon.ts`.

- Si `whatsapp` est rempli (exemple `34600111222`), le formulaire ouvre une conversation WhatsApp.
- Sinon, si `email` est rempli, il ouvre le mail du salon.
- Sinon, la demande est enregistrée dans `data/reservations.json` sur la machine qui fait tourner le site.

Les horaires exacts, l’adresse de rue et les tarifs ne sont pas affichés : ils ne figuraient pas sur les photos.
